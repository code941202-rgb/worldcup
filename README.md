# ⚽ 2026 북중미 월드컵 승부예측 대진표

학교 후배와 둘이서 2026 월드컵 결과를 예측하고 승률을 겨루는 웹앱입니다.
2025년 12월 5일 조추첨으로 확정된 48개국 본선 진출국이 반영되어 있습니다.

## 실행 방법
`index.html` 파일을 더블클릭해서 브라우저로 열면 바로 됩니다. (설치 불필요)

## 사용법
1. **프로필 선택** — 상단의 `나` / `후배` / `실제결과` 중 편집할 프로필을 고릅니다.
2. **32강 배치** — 아래 참여국 칩을 32강 빈 칸에 **드래그**하거나, 칩을 **클릭**해서 선택한 뒤 빈 칸을 클릭합니다.
   - `🎲 32강 자동배치` 버튼으로 무작위 배치도 가능합니다.
3. **승자 선택** — 경기에서 이길 것 같은 팀을 **클릭**하면 다음 라운드(16강→8강→4강→결승→우승)로 자동 진출합니다.
4. **공유** — `🔗 공유` 버튼으로 코드를 복사해 후배에게 보내거나, `💾 파일로 저장`으로 JSON을 저장합니다.
5. **가져오기** — 후배에게 받은 코드/파일을 `📥 가져오기`에서 원하는 프로필 칸에 불러옵니다.
6. **채점** — 실제 경기 결과가 나오면 `실제결과` 프로필에 똑같이 입력한 뒤, `📊 승률 비교` 버튼으로 둘의 적중률을 비교합니다.

## 채점 방식
- 각 라운드(32강·16강·8강·4강·결승)별로 **실제 진출 팀 중 맞힌 수**로 점수를 매깁니다.
- **우승 적중은 가중치 3배**로 계산합니다.
- 적중률 = 적중 점수 / 가능한 총점 × 100

## 데이터 저장
모든 예측은 브라우저 `localStorage`에 자동 저장됩니다. 같은 브라우저에서 다시 열면 그대로 유지됩니다.

## 파일 구성
- `index.html` — 화면 구조 및 스타일
- `data.js` — 48개국 정보(한글명/국기/조)와 토너먼트 구조
- `app.js` — 배치·승자선택·공유·채점 로직
